# 💕 HeartLink

🔗 **Live demo:** https://mo9-crypte.github.io/Heartlink/

HeartLink is an interactive web gift that tells a love story through shared memories. It begins with a playful question, "You Love Me?", and then takes the visitor through a scrolling journey of photos, moments, and messages between two people.

## ✨ Features

- Animated floating hearts background
- Smooth transition between layers of the story
- Photo memories section
- Contact section
- Fully responsive design for phones and desktops

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (canvas animation and interactions)

## 🚀 How to Run

1. Open the live demo link above, or
2. Download the repository and open `index.html` in any browser.
